# Веб-приложение для практики буддийских медитаций

## Технологии
- HTML / CSS / PHP / MySQL / JavaScript 

## Структура
meditation/
├── config/config.php # Подключение к БД
├── pages/ # Страницы
├── actions/ # POST-логика
├── admin/ # Админ-панель
└── assets/ # CSS/JS/audio/images

## Установка
1. Импортируйте SQL
2. Скачайте архив
3. Распакуйте архив в папку веб-сервера:
    OpenServer: domains/meditation/
    XAMPP: htdocs/meditation/
4. Настройте config.php
5. Настройте SMTP для отправки писем


## Функции
- Регистрация/авторизация
- Восстановление пароля
- Таймер медитаций + сохранение сессий
- Профиль
- Статистика
- Благовоние
- Тест с подбором медитации
- Админ-панель
